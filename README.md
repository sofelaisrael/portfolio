# Ken Sh.in — Portfolio

Creative developer portfolio built with React, TypeScript, and Vite.

## Stack

- **Framework:** React 18 + TypeScript
- **Build:** Vite 5
- **Styling:** Tailwind CSS 3
- **Animation:** GSAP 3 (ScrollTrigger, SplitText)
- **Smooth Scroll:** Lenis
- **Routing:** React Router 6
- **Icons:** Lucide React, Tech Stack Icons
- **Email:** EmailJS
- **Fonts:** Inter, JetBrains Mono

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
